# JavaScript Calculator

A simple interactive calculator built using **HTML, CSS, and JavaScript** as part of my Week 2 Web Development learning journey.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling
- Interactive user input
- Dynamic result display

## Technologies Used

- HTML5
- JavaScript
- DOM Manipulation
- Git & GitHub

## How It Works

The user enters two numbers and selects an arithmetic operation. JavaScript reads the input values, performs the selected calculation, and dynamically updates the result on the webpage.
